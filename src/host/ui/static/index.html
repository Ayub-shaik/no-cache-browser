This is the NCB product window. Use the tab strip, address bar, and No-cache / Save nothing toggle to drive the content surface. Toggle ON uses an ephemeral browsing context (cookies/storage discarded with that mode) plus HTTP cache off and service-worker bypass. Duplicate opens another tab in the same session (login/cookies carry over). Closing a tab does not stop in-flight downloads while NCB is running; quitting the process stops them.
